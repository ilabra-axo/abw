# Legacy harvest

An inventory of the legacy system (`Replicant-Partners/fermi` at `a3cea516`, plus the tenant clients in `~/kask`, `~/rabble` and `fermi/static`), made so that nothing is lost by omission. Each item has a disposition. Items marked `drop?` are **proposals** until the owner approves them in an ADR.

| File | Covers | Method |
| --- | --- | --- |

| [agents.md](agents.md) | 104 curated agents; what each strategist really does (code vs prompt-only) | Agent-read cards, prompts and orchestration code |
| [modules.md](modules.md) | 28 crates, about 120 modules, the five loops, Shapley; kernel port candidates with oracles | Agent-read code and loop docs |
| [tenants.md](tenants.md) | Endpoints each tenant client calls, matched to legacy routes | Generated by `harvest_tenants.py` |
| [tenants-notes.md](tenants-notes.md) | Per-tenant location, claims, and minimum core surface | Written from the above |

## Headline findings

1. **Strategists are mostly prompt text.** The pipeline, debate and vote strategists have no orchestration code. MoE routing's calibration-weighted synthesis and routing records aren't implemented. Only cohere_and_coordinate has substantial code, and even there the homophily guard, the cross-member assignment check and the anti-convergence check exist only in its prompt. PROT-01 and PROT-02 make each of these a tested requirement.
2. **Shapley credit has probably never run on real data** (its input table was empty at the last audit). Per-agent "calibration" signals copy the team Brier to every agent. PROT-03 and PROT-10 require the real thing.
3. **Append-only was mostly a comment.** Only 4 tables were enforced, none against DELETE, and six human-decision queues update in place. The new core enforces this from M1 (T2, T3, T6).
4. **Several loops have never had input** (projection accuracy, routing provenance, Loop 3.B). PROT-06 requires each gate to be shown firing.
5. **The Monte Carlo executor has 3 direct tests**, and the sampler is plain HMC, not the NUTS the docs claim. Kernel ports are certified against independent oracles (PROT-04, PROT-05).
